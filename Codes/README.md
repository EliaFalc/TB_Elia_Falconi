# Codes utilisés

Ce dossier contient deux scripts Python développés dans le cadre du travail de bachelor.

Ces scripts ont été utilisés pour produire :

- la carte du potentiel lié à l’altitude ;
- la carte du potentiel lié au nombre de jours avec présence de neige.

Les traitements, les critères appliqués et les étapes de calcul suivent la méthodologie décrite dans le rapport du travail de bachelor.

Les scripts permettent notamment de traiter les données d’entrée, d’appliquer les règles définies dans la méthodologie et de générer les cartes finales utilisées dans l’analyse.

> **Remarque :** l’exécution correcte des scripts nécessite les données sources correspondantes ainsi que les bibliothèques Python indiquées dans les fichiers.
