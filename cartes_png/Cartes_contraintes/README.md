# Cartes des critères d’exclusion



Ces cartes ne figurent pas toutes directement dans le rapport du travail de bachelor. Elles représentent les différents limites et seuils territoriaux sélectionnés pour construire le masque d’exclusion.



Ce filtre permet d’identifier les zones du canton du Tessin considérées comme incompatibles ou peu adaptées à l’implantation d’installations photovoltaïques, selon les contraintes définies dans la méthodologie.



Les cartes sont fournies à titre complémentaire afin de documenter les différentes étapes de l’analyse et d’améliorer la transparence du processus de sélection des zones exclues.



> \*\*Remarque :\*\* les critères, les seuils appliqués et les sources de données correspondantes sont décrits dans le rapport du travail de bachelor.
