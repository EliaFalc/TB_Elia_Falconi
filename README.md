# Cartes et scripts du travail de bachelor

Ce dépôt contient les principales données cartographiques et les scripts Python utilisés dans le cadre de ce travail de bachelor.

## Contenu du dépôt

Le dépôt est organisé en plusieurs sections :

- **Cartes au format PNG**  
  Versions exportées des cartes, destinées à la consultation, à l’illustration et à l’intégration dans le rapport.

- **Cartes au format GeoTIFF**  
  Données raster géoréférencées utilisées pour les analyses spatiales. Ces fichiers peuvent être ouverts dans un logiciel SIG tel que QGIS ou ArcGIS.

- **Scripts Python**  
  Codes développés et utilisés pour le traitement des données et la génération de certaines cartes

Les différents fichiers peuvent être téléchargés directement depuis les dossiers correspondants.

## Caractéristiques des données cartographiques

Sauf indication contraire, les cartes mises à disposition présentent les caractéristiques suivantes :

- **Système de référence spatial :** EPSG:2056 — CH1903+ / LV95
- **Dimensions du raster :** 2 419 × 3 818 pixels
- **Résolution spatiale :** 25 m × 25 m par cellule
- **Format géospatial principal :** GeoTIFF

## Méthode d’élaboration

Les cartes ont été élaborées par l’auteur dans le cadre du travail de bachelor, à partir :

- des sources de données citées dans le rapport ;
- des traitements géospatiaux réalisés au cours de l’étude ;
- des informations recueillies lors des entretiens avec les experts mentionnés dans le rapport ;
- des fonctions de potentiel et des hypothèses méthodologiques décrites dans le rapport.

Les fichiers publiés dans ce dépôt correspondent aux résultats cartographiques utilisés pour l’analyse et la présentation des résultats.

## Utilisation des données

Les cartes au format JPEG peuvent être utilisées à des fins de consultation et de visualisation.

Les fichiers GeoTIFF permettent une réutilisation dans un environnement SIG, notamment pour :

- visualiser les résultats avec leur géoréférencement ;
- comparer les différentes cartes de potentiel ;
- effectuer des analyses spatiales complémentaires ;
- reproduire certaines étapes du travail.

Les scripts Python sont fournis afin d’améliorer la transparence et la reproductibilité de la méthodologie.

## Sources et limites

Les données sources, leurs références, ainsi que les principales limites méthodologiques sont décrites dans le rapport du travail de bachelor.

La précision et l’interprétation des cartes dépendent notamment :

- de la résolution des données d’origine ;
- des hypothèses retenues pour les fonctions de potentiel ;
- des appréciations formulées par les experts consultés ;
- des traitements et simplifications appliqués au cours de l’analyse.

Il est donc recommandé de consulter le rapport avant toute réutilisation ou interprétation des résultats.
