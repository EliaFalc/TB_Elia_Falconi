# Cartes utilisées



Ce dossier contient les cartes exportées au format PNG et dans un format utilisable sur SIG dans le cadre du travail de bachelor.



Il comprend :



\- les cartes présentées dans le rapport ;

\- les cartes utilisées comme masques d’exclusion pour identifier les zones du canton du Tessin considérées comme incompatibles avec l’implantation d’installations photovoltaïques.



Les fichiers sont principalement destinés à la visualisation et à l’illustration des différentes étapes de l’analyse.



Les masques d’exclusion représentent notamment les secteurs écartés pour des raisons territoriales, environnementales, techniques ou réglementaires, conformément à la méthodologie décrite dans le rapport du travail de bachelor.



> **Remarque :** les cartes au format PNG sont fournies uniquement à des fins de visualisation et ne contiennent aucune information géospatiale. Les données géoréférencées correspondantes sont disponibles aux formats GeoTIFF ou GPKG.
